# Market

Module autonome issu du bot Market v2.7 fourni : surveillance Leboncoin/Vinted,
bot Discord distinct de ChamoxisBOT et recherches gérées par leurs propriétaires.

Voir [le guide d’installation, d’utilisation, de migration et les améliorations repérées](../../docs/market.md).

Depuis la racine du dépôt : `python -m modules.market.main`.
Configuration : `modules/market/.env`. Données : `data/market/`.
